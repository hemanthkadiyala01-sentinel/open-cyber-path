# OpenCyberPath: Career-to-Application Toolkit

This toolkit extends the ten role-oriented learning paths with a connected journey from beginner learning to evidence-led job applications. It is designed as an independent, free-to-explore learning aid; it is not a recruiting service, paid placement service, or guarantee of employment.

## User journey

1. **Choose a direction.** Red Team / authorized testing, Blue Team / defense, Purple Team / detection collaboration, DFIR, Cloud Security, or GRC.
2. **Build foundations.** Networking, operating systems, HTTP, scripting basics, Git, safe lab practice, and technical writing.
3. **Complete guided practice.** Follow one of the ten canonical learning paths; use local exercises, synthetic data, CTFs, or provider labs that explicitly authorize the activity.
4. **Keep evidence.** Save readable reports, project READMEs, assumptions, limitations, sanitized screenshots, and remediation notes.
5. **Prepare application materials.** Create a truthful text-first resume, project summaries, and links to demonstrable work.
6. **Search and apply.** Use external job platforms and official employer pages; verify the vacancy, requirements, eligibility, deadlines, and application domain.
7. **Track next actions.** Keep a private, local list of genuine opportunities and follow-ups.

## Career directions

The Career Hub maps directions to the current canonical roadmaps:

| Direction | Existing learning path | Example evidence to build |
|---|---|---|
| Red Team / authorized testing | Application Security & Bug Bounty | A training-lab report with scope, evidence, impact, and remediation |
| Blue Team / defense | SOC Analyst / Blue Team | A synthetic-log triage worksheet with reasoned conclusions |
| Purple Team / detection collaboration | Threat Hunting & Detection Engineering | A detection hypothesis, synthetic test case, and evaluation note |
| DFIR | Digital Forensics & Incident Response | A fictional evidence timeline and handling worksheet |
| Cloud Security | Cloud Security | A fictional architecture review with risk and verification notes |
| GRC | GRC & Security Fundamentals | A risk register with stated assumptions, owners, and evidence requests |
| Penetration Testing / Red Team | Penetration Testing & Authorized Red Team | A scope-limited training-lab report with remediation and retest criteria |
| Security Engineering / DevSecOps / IAM | Security Engineering, DevSecOps & IAM | A fictional architecture review and pipeline security checklist |
| Threat Intelligence / Ethical OSINT | Threat Intelligence & Ethical OSINT | A sourced intelligence brief that records uncertainty and privacy boundaries |
| Malware Analysis / Reverse Engineering | Malware Analysis & Reverse Engineering | A safe static-triage report using provided metadata and reputable analysis reports |

These are recommended starting points, not claims that a learner is ready for a corresponding job after one module. Professional titles vary between employers. The NIST NICE Framework is a useful reference for comparing actual work roles, tasks, knowledge, and skills.

## Hacker-hat terminology

The explainer covers the six requested informal labels: white, black, grey, green, blue, and red hats. The terms do not all describe standardized occupations and their meanings can vary by community. The product emphasizes authorization, defined scope, responsible reporting, and harm prevention. It does not present malicious or unauthorized behavior as a job pathway.

Red Team, Blue Team, and Purple Team are presented separately from hat terminology:

- **Red Team:** authorized offensive security simulation or assessment with defined scope and rules.
- **Blue Team:** defensive monitoring, investigation, detection, and response.
- **Purple Team:** a collaborative practice for sharing offensive test outcomes with defenders to improve detections and controls; it is not always a separate formal job title.

## Resume Studio

The studio provides:

- A live, one-column, text-first resume preview with common headings.
- Fields for name, target role, optional contact links, education, skills, projects, and certifications.
- A basic local keyword comparison against a pasted job description.
- TXT and HTML downloads, browser-local draft saving, and browser Print / Save as PDF.

The keyword review checks a limited built-in dictionary. It is not a commercial applicant tracking system, does not score a real employer's ranking logic, and cannot guarantee that a resume will pass an ATS or be selected. Users should not include credentials, OTPs, identity numbers, full home addresses, or other unnecessary sensitive information. Saved drafts remain in the current browser's local storage; avoid using the save feature on a shared device.

## Job Search Hub

The Job Hub links to external job-search providers and official early-career pages. Search results, eligibility, deadlines, terms, and vacancies can change. Open Cyber Path does not scrape or certify live listings and does not endorse every result returned by a provider. The user should apply through the official employer or platform flow after confirming the vacancy is genuine and appropriate.

The application-safety notice is grounded in the Government of India's National Career Service warning that its services are free of cost and that fraudulent parties may falsely claim association with NCS. Users should not pay a person to guarantee an interview, referral, job, or offer.

## Application Demo and Tracker

The demo vacancy is explicitly fictional. It only checks a preparation checklist and reports local readiness; it never submits an application, sends email, calls a company API, or claims that an application has been sent.

The tracker stores opportunity notes, status, and next actions in browser local storage. The user can export a JSON backup, update the status, or remove an item. No account or backend is required in this first version. Do not put passwords, OTPs, identity documents, private recruiter messages, or other unnecessary sensitive data in tracker notes.

## Boundaries and limitations

- No guarantee of placement, salary, interview, internship, certification, bounty, or freelance income.
- No live job feed or automatic application submission.
- External links may redirect, require an account, or change; verify current details at the provider.
- Resume keyword coverage is only a lightweight review aid.
- Browser-local information can be lost when site data is cleared and should not be stored on shared computers.
- The toolkit uses the current ten-path roadmaps rather than duplicating curriculum content.
