# Resource verification policy

OpenCyberPath is a curated directory, not a mirror of external courses. We link to original providers and describe resource access as accurately as practical.

## Access labels

- `free_learning`: the listed learning content is currently described by the provider as free.
- `open_source`: software/source is published under a licence; operating or hosting it may still cost money.
- `free_documentation`: docs or reference material are publicly accessible; associated products, exams, or labs may be paid.
- `free_tier`: only selected usage or content is available for free.
- `paid_or_trial`: temporary trial or paid access; do not present this as part of the zero-cost path.
- `needs_review`: cost/access could not be reliably confirmed.

Never use a vague `free` badge to imply all of a provider's content, certifications, infrastructure, or advanced features are free.

## Minimum metadata for an entry

Each entry should include:

- Stable ID and resource title.
- Official URL.
- Topics and intended learner level.
- Access category and a plain-language access note.
- Account, hardware, and internet requirements, where known.
- Date last verified in ISO format (`YYYY-MM-DD`).
- A short description written by OpenCyberPath, not copied from the provider.

## Verification process

1. Prefer an official provider website or its official repository.
2. Open the link and confirm it describes the resource we list.
3. Check for registration, free-tier limits, trial expiry, paid extras, cloud costs, and hardware prerequisites.
4. Record what was actually checked. Use `needs_review` when unsure.
5. Recheck links periodically and when a learner reports a change.
6. Keep third-party code, rules, documentation, images, and datasets within their licence and terms. Linking is preferred to copying.

## Important limitation

A link being present in this repository does not mean OpenCyberPath has run the lab or independently tested every feature. Resource access conditions can change after the listed verification date.
