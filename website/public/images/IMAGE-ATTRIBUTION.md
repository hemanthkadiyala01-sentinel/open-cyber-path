# Learning illustrations

The four editorial learning illustrations in this folder were generated specifically for the OpenCyberPath learning interface. They are decorative educational illustrations, not screenshots of real systems, real users, provider logos, or evidence of actual incidents.

Files:
- `threat-hunting.jpg` — defensive investigation and log analysis
- `bug-bounty.jpg` — web security study in a controlled practice context
- `handwritten-notes.jpg` — notebook-style learning and visual diagrams
- `command-cheatsheet.jpg` — terminal and network fundamentals

Resource provider names remain text links to their original providers. Do not present these illustrations as provider-owned artwork or as photos of real labs.

## v0.5 topic-specific artwork

The following original AI-assisted illustrations were created for OpenCyberPath and optimized locally for web delivery: `learning/foundations-network.webp`, `learning/soc-investigation.webp`, `learning/bug-bounty-research.webp`, and `learning/detection-engineering-lab.webp`. They are decorative educational artwork. They do not depict live systems, real users, provider-owned products, or actual incident telemetry. For sample evidence and numeric metrics, use the interactive homepage panel, which reads the project’s bundled synthetic CSV datasets.

New conceptual diagrams: `learning/hunt-sample-timeline.svg` and `learning/http-exchange.svg`. Their labels describe example workflows; the bundled CSV remains the source of truth for the actual sample rows.

The notebook SVG uses project-authored readable labels instead of generated pseudo-text. It teaches a simple evidence workflow; always rely on source logs and the linked handouts for the full lesson.
