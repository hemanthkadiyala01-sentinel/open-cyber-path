# OpenCyberPath practice data

Datasets in this folder are designed for learning and are synthetic unless a file explicitly says otherwise. They do not represent a real customer, user, endpoint, or incident.

- `windows-process-creation-samples.json`: simplified teaching events
- `detection-evaluation-cases.csv`: labelled synthetic cases for the sample evaluator
- `threat-hunt-auth-dns-samples.csv`: invented authentication and DNS activity for a basic hunt
- `bug-bounty-scope-worksheet.csv`: blank planning worksheet; it contains no target list

Use the samples offline or inside your own practice environment. For web testing, use the intended PortSwigger Web Security Academy labs or an isolated local training application. Always read the exact written scope and rules before working on any real program. Never test an arbitrary public target, attempt access to another person's data, or perform a destructive test.
