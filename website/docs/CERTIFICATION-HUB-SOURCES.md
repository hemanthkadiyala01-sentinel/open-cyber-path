## Rules for maintaining this data

1. Use the issuer's official credential page and the exam-specific guide as the source of truth. Aggregators, forums, training vendors and search snippets can help discovery but should not override the issuer.
2. Treat prices as regional snapshots, not quotes. Check taxes, currency, vouchers, training bundles, exam retakes, lab access and renewal fees before a learner buys anything.
3. Keep these concepts distinct: free learning, a learning-platform achievement/badge, a course-completion certificate, a paid professional certification exam, and a separately priced practical assessment.
4. Keep high-level syllabus summaries in OpenCyberPath's own words. Link to official objectives rather than copying full exam guides or reproducing confidential exam questions.
5. Update `verifiedOn` only after rechecking official issuer pages. When an exam outline changes, add a dated notice and make the scope/effective date clear.
6. A successful HTTP response does not prove a source is current or that pricing/eligibility is unchanged. Recheck it when a learner plans to book.

## Credential card images

Where an issuer provides a public, matching digital badge image, the card uses the image hosted by Credly. This patch maps official badge images for ISC2 CC/CISSP/CCSP, Cisco CCNA Cybersecurity, AWS Certified Security – Specialty, ISACA CISA/CISM, GIAC GCIH and IBM SkillsBuild Cybersecurity Fundamentals. The Cisco Cybersecurity Essentials learning card uses its matching course badge image. These are actual badge artwork, not recreated certificate claims. For other cards, the interface displays a favicon served for the issuer's official website, with an initials fallback when remote images fail. The link beside each card remains the authoritative issuer page. OpenCyberPath does not claim that a learner holds any of these credentials.

## Official-source monitor is maintainer tooling

The daily source watcher is retained in GitHub Actions for repository maintainers: it catches unreachable public URLs and content changes that may warrant checking an issuer's page. It is not exam-seat inventory, not a registration API, and not useful as a noisy badge on every public card. The public-facing monitor panel has therefore been removed from the Certifications Hub. Fees, syllabus versions, prerequisites and actual booking slots still require verification at the issuer.
