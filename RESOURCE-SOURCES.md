# Resource source notes

OpenCyberPath links learners to source owners instead of rehosting external courses. The following official documentation pages were checked while preparing v0.3 content (17 October 2026). Providers can change their offerings, so check the original page before beginning.

## Threat hunting and defensive learning
- Microsoft Defender XDR hunting overview: https://learn.microsoft.com/en-us/defender-xdr/hunting-overview
- Kusto Query Language overview: https://learn.microsoft.com/en-us/kusto/query
- MITRE ATT&CK knowledge base: https://attack.mitre.org/
- CyberDefenders blue-team labs: https://cyberdefenders.org/blue-team-labs/

## Web security and bug-bounty foundations
- PortSwigger Web Security Academy: https://portswigger.net/web-security — official free interactive web-security training and labs.
- OWASP Web Security Testing Guide: https://owasp.org/www-project-web-security-testing-guide/ — web application testing reference.
- OWASP Juice Shop: https://owasp.org/projects/juice-shop — intentionally vulnerable application created for security training; keep local/isolated instances private.
- HackerOne scope guidance: https://docs.hackerone.com/en/articles/8494552-defining-scope
- Bugcrowd engagement details: https://docs.bugcrowd.com/researchers/engagement-management/details/

## General content rules
- Label a third-party access model conservatively; distinguish free learning, open source, and free tiers.
- Do not claim that a provider is completely free if some labs, products, or cloud services may cost money.
- Do not invent audience numbers, ratings, testimonials, job outcomes, or bounty rewards.
- Keep bug-bounty exercises inside intentionally supplied training environments or exact written scope.
- Threat-hunting datasets shipped with this project are synthetic. Do not present them as production telemetry or as proof of real-world detection performance.
- Prefer a helpful correction or a newer official link over adding more unverified resource cards.

## DFIR, cloud security, and governance resources added in v0.6

- NIST SP 800-86, *Guide to Integrating Forensic Techniques into Incident Response*: https://csrc.nist.gov/pubs/sp/800/86/final — foundational computer and network forensic guidance. It is not an all-inclusive forensic playbook or legal advice.
- NIST digital forensics project: https://www.nist.gov/programs-projects/digital-forensics — official context on digital evidence and forensic technology testing.
- AWS training: https://aws.amazon.com/training/ — provider learning catalogue; individual courses and lab access can have different terms.
- Microsoft Learn Azure security training: https://learn.microsoft.com/en-us/training/browse/?products=azure&subjects=security — official training search; creating cloud resources can incur charges.
- NIST Cybersecurity Framework 2.0: https://www.nist.gov/cyberframework — framework resources for cybersecurity risk outcomes and improvement planning.
- NIST CSF 2.0 Quick-Start Guides: https://www.nist.gov/cyberframework/quick-start-guides — starter materials for applying the framework.
- CIS Critical Security Controls: https://www.cisecurity.org/controls — prioritised safeguards; check current terms for downloads or related services.
- CISA Cyber Essentials: https://www.cisa.gov/sites/default/files/publications/19_1106_cisa_CISA_Cyber_Essentials_S508C_1.pdf — introductory cyber-readiness guidance. Check the CISA site for newer guidance before treating a static document as current.

The v0.6 DFIR, Cloud Security, and GRC worksheets use fictional scenarios. They help practise how to reason and document; they are not a forensic certification, cloud compliance assessment, or formal audit.
