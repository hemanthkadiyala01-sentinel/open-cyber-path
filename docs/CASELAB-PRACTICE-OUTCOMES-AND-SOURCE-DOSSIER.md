# CaseLab practice outcomes and source dossier — revision 1.2.0

## What the learner is practising

The Live Incident Operations feed now displays the specific skill objectives and expected work product attached to each category-matched drill before the learner starts it. The drill repeats these objectives at launch. This prevents a headline and a generic category template from being presented as a complete incident-specific reconstruction. Each drill states that its local event records are synthetic and not victim telemetry.

The current blueprints cover: dependency provenance and CI exposure; affected-version triage and patch validation; certificate-chain scope; AI-agent tool-scope review; API request and token analysis; third-party impact scoping; identity/OAuth correlation; endpoint timeline and recovery; and generic source verification.

## Midnight Blizzard source dossier

Revision 1.2.0 expands the four-source register to twelve references and groups them by learning purpose: primary incident disclosures and updates, government response, technical response guidance, defender investigation playbooks, threat-actor context, and independent reporting/detection analysis. Source records have distinct `sourceGroup` and `sourceType` fields, support statements, publication/access notes, and canonical publisher URLs.

The source register includes the original public disclosure, responder guidance, follow-up update, CISA directive and announcement, Microsoft incident-response and OAuth investigation playbooks, MITRE ATT&CK threat-group context, independent reporting, detection analysis, and publisher-hosted attack-flow illustration. Independent analysis is marked as secondary; no secondary report is treated as proof of private victim telemetry.

## What the learner should produce

- An evidence-linked UTC timeline.
- A fact-versus-inference matrix.
- A competing-hypothesis assessment and missing-evidence list.
- A scoped, proportionate response plan.
- A post-response validation plan with expected observations and an accountable closure owner.

## Integrity and limitations

The offline evidence pack contains synthetic training records and an original simplified public-incident diagram. It is not Microsoft telemetry. This case remains marked `draft-awaiting-human-review` until independent technical and educational review is complete. External sources can change; this source list was checked on 2026-10-24, and users must recheck source status and applicable terms before reproducing material.
