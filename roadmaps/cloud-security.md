# Cloud Security roadmap

**Purpose:** Understand shared responsibility, identity, network boundaries, storage exposure, logging, recovery, and secure configuration.

**Prerequisites:** Basic networking and account/permission concepts. The starter route uses a fictional architecture and review worksheet; creating live cloud resources is optional and may cost money.

## Modules

1. **Understand cloud responsibility** — compare service models and map provider versus customer responsibilities for a fictional workload.
2. **Review identity and access** — examine least privilege, roles, service identities, MFA, credential handling, and safe recovery access.
3. **Check network and data boundaries** — review public exposure, ingress/egress, private endpoints, storage access, encryption, and secrets handling.
4. **Review logging and recovery** — record required audit events, retention, routing, backups, and evidence of restore testing.
5. **Present a risk-based review** — rank gaps, name evidence needed, assign an owner role, recommend treatments, and document what was not tested.

## Capstone

Use the Cloud Security Posture Review workbook to assess a fictional design. Submit a trust-boundary diagram, completed checklist, prioritised risks, suggested treatments, and verification steps.

**Cost note:** Documentation may be free even when provider accounts, lab time, or cloud resources have limits or charges. Verify current pricing before creating anything.
