# OpenCyberPath learning tiers

Choose the tier by current skills, not by confidence or job title. You may move between tiers as needed. All links are external unless a resource is explicitly labelled as OpenCyberPath content.

## Beginner — Build the foundation
- Computer basics, files, processes, permissions, command line.
- TCP/IP, DNS, HTTP/HTTPS, ports, basic Linux and Windows event logs.
- Learn what an event, alert, incident, and SIEM do.
- Practice with sample JSON/CSV data and the handwritten-style SOC/SIEM notes.
- Evidence: explain five log fields and write one evidence-based triage note.

## Intermediate — Operate and investigate
- Use Wazuh or a suitable Splunk learning environment.
- Learn event normalization, searching, alert triage, MITRE ATT&CK mapping, and case notes.
- Write a narrow rule and test it against benign and suspicious cases.
- Practice false-positive and false-negative analysis.
- Evidence: a reproducible detection report with TP, FP, TN, FN and limitations.

## Advanced — Engineer, evaluate, and validate
- Understand log-source coverage, rule dependencies, time windows, tuning, and detection lifecycle.
- Learn Sigma and platform-specific query syntax (e.g., SPL/KQL) from official materials.
- Separate development cases from held-out validation data where possible.
- Validate full telemetry flow and recovery in an authorized lab.
- Document performance, data quality, limitations, and change history.
- Evidence: a versioned rule pack, test corpus, evaluation report, and verified end-to-end investigation.

## Job preparation milestones
1. Match skills to current job descriptions.
2. Finish two or three small, reproducible projects.
3. Write honest READMEs and sanitized evidence reports.
4. Practice explaining decisions, uncertainty, and false-positive tradeoffs.
5. Prepare a focused résumé and interview examples.
6. Apply to suitable roles; a roadmap or certificate does not guarantee employment.
