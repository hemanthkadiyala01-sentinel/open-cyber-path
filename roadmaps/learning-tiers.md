# OpenCyberPath career-path index — 10 career visions

Choose one main route based on the work you find interesting. All ten are structured learning visions; each has prerequisites, sequenced modules, safe practice, portfolio evidence, and a capstone. The routes overlap on purpose, and learners can add adjacent skills over time. No route guarantees employment.

## The 10 career visions

1. [SOC Analyst / Blue Team](soc-blue-team.md) — log sources, alert triage, detection basics, and incident notes.
2. [Threat Hunting & Detection Engineering](threat-hunting-detection-engineering.md) — hypotheses, baselines, detections, queries, and evaluation metrics.
3. [Digital Forensics & Incident Response (DFIR)](digital-forensics-incident-response.md) — evidence integrity, event timelines, incident handling, and reporting.
4. [Application Security & Bug Bounty](application-security-bug-bounty.md) — HTTP, common web risks, authorised labs, secure design, and responsible disclosure.
5. [Cloud Security](cloud-security.md) — identity, network boundaries, configuration, logging, and recovery.
6. [GRC & Security Fundamentals](grc-security-fundamentals.md) — risk, control mapping, compliance evidence, and communication.
7. [Penetration Testing & Authorized Red Team](penetration-testing-red-team.md) — scope, rules of engagement, low-impact testing, findings, and remediation.
8. [Security Engineering, DevSecOps & IAM](security-engineering-devsecops-iam.md) — secure architecture, identity, pipeline checks, secure defaults, and recovery.
9. [Threat Intelligence & Ethical OSINT](threat-intelligence-ethical-osint.md) — source reliability, public-data research, indicators, privacy, and intelligence briefs.
10. [Malware Analysis & Reverse Engineering](malware-analysis-reverse-engineering.md) — safe sample handling, metadata, static triage, defensive interpretation, and reports.

## Shared module standard

Each module should state prerequisites and learning objectives; explain concepts in plain language; point to original-provider resources with access notes; provide a safe lab or worksheet; define the evidence a learner should save; explain the expected result and limitations; and suggest one next step.

Practise offensive security only against owned systems, intentionally vulnerable training labs, or targets explicitly covered by permission and documented scope. These roadmaps are self-study guides, not guarantees of a job, salary, certification, client, or bounty reward.
